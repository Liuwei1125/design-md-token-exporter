# Security Policy

## Supported Versions

The current supported version is `0.1.x`.

## Reporting A Vulnerability

Please report security or privacy issues through GitHub Security Advisories if available, or open a GitHub issue with a concise description that avoids sharing sensitive page data.

Include:

- Extension version.
- Browser and OS.
- Steps to reproduce.
- Expected and actual behavior.
- Whether the issue involves permissions, storage, exports, or page analysis.

## Privacy Scope

Design.md Token Exporter is local-first in the MVP. It does not call AI APIs, make default network requests, upload page content, or collect browsing history.
